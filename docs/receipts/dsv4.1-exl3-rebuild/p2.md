## The arithmetic

- Rows: a launch's threadgroup is one simdgroup; q lanes share a column (C = 32 / q columns a simdgroup), each lane
  decodes 16 / q of the column's 16 values of a k tile with P1's index table and takes the others by `simd_shuffle`;
  each lane keeps rp rows. Every row's chain is P1's: k ascending, product = fp32(x'_k) * fp32(W_q[k][c]) exact,
  TwoSum next = fl(high + p), part = fl(next - high), low = fl(low + fl(fl(high - fl(next - part)) + fl(p - part))),
  output fl(high + low). Nothing is shared between rows except the decoded weight, whose bits are the same in every
  lane, so row r's bits do not depend on the rows beside it or on (rp, q).
- Groups: 2 rows 1x2, 3-4 rows 1x4, 5-8 rows 1x8, 9-16 rows 2x8, chosen from tf-exl3-bench sweeps of 1x2 to 8x2 at
  the seven dense shapes on both machines. 3 to 16 rows take them while (N / 16) * ceil(rows / 8) < 12 * GPU cores:
  on the M4 Pro (20 cores) they lost where the hoisted kernel launched 288 or more simdgroups and won at 160 or fewer;
  on the M5 Ultra (64 cores) they lost at 2048 and won at 640.
- SwiGLU: `tf_exl3_swiglu` rotates gate's and up's sums out to bf16 with `tf_exl3_rotate_out`'s expression, then
  `tf_dsv41_f_swiglu`'s: gc = clip(bf16(g), -inf, limit), uc = clip(bf16(u), -limit, limit) (NaN kept),
  y = bf16(precise::divide(gc, 1 + precise::exp(-gc)) * uc), yq = act_quant's e4m3 round trip over each 128-wide block
  (the 32 lanes of a block), limit = 10. The expressions are copied, not the file, so fused.metal's
  `fp contract(off)` stays out of `core_exl3_rows`; none of the copied expressions has a contractible a * b + c.

## Gates and results

- Row invariance (`zig build test-exl3-gpu`, M4 Pro): at 2, 3, 4, 8 and 16 rows on P1's eight dense shapes, with NaN
  and +-Inf in x, every row's sums and outputs equal that row launched alone through `tf_exl3_matmul_row` and the
  launch equals `tf_exl3_matmul_hoisted`; one row's first, middle and last 128 columns equal the serial reference.
- Gate/up: at 1, 2, 3, 4, 8 and 16 rows (k 5120, n 2304; mul1 2.5 / mcg 2 bits, 3inst 6 / mul1 1.5 bits with biases),
  with no cores and with all routed to the rows kernels, y and yq equal w1 and w3 through `tf_exl3_matmul_hoisted` then
  main's `tf_dsv41_f_swiglu`; both clamps are reached.
- Planted faults, run once and reverted: dropping the rows TwoSum error term fails three GPU tests; dropping the up
  clamp fails the gate/up test.
- Kernel contract on M4 Pro, `tf-kernel-contract --only exl3`: `SUMMARY 12 kernels: 12 pass gates 1-4, 0 fail, 0 known
  findings; 3 controls: 3 red as planted, 0 missed; 0 limit problems`.
- float64 is not compared here: every claim is bit-equality to P1's kernel, main's kernels or the serial reference.
- Speed, GPU seconds (mean of 30, `tf-exl3-bench --mode prefill --candidate rows`, rotations included), hoisted against
  rows at K x N and rows. M4 Pro: 5120 x 2304 2/4/8 rows 497/309, 659/407, 944/634 us; 5120 x 1280 8 rows 894/356;
  5120 x 512 8 rows 952/219; 4096 x 1024 4 rows 440/203. M5 Ultra: 5120 x 2304 8/16 rows 774/224, 772/383; 2304 x 5120
  8 rows 357/191; 8192 x 5120 8 rows 1208/640. Counts the rule keeps on the hoisted kernel ran slower in the rows kernels.
