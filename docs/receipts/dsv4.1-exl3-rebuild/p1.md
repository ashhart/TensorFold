## The arithmetic, from `exl3_format.zig`

- A tile holds 256 values in a ring of R = 128 * halves bits. Value p's 16-bit window ends at
  E(p) = ((p + 1) * halves - (halves odd ? (p + 1) & 1 : 0)) / 2, which is `streamEnds` for whole and half widths; it
  starts at (E - 16) mod R and reads MSB-first from little-endian int16 pairs (`streamBit`).
- The index table: for its column c, a lane keeps for each tile row r the position p = 8l + j with l = 4(c % 8) +
  (r % 8) / 2 and j = 4(c / 8) + 2(r / 8) + r % 2, the inverse of `tilePlacement`, as (word, bit offset, next word);
  it is computed once a launch, the same for every k tile.
- The codebooks round once to fp16 a state: mul1 as fp16(h * fp16(0x1EEE) + fp16(0xC931)) with the fp32 fma exact
  before the round, mcg and 3inst as fp16(lo) + fp16(hi) after the mask and flip (`exl3_projection_decode.zig`'s test
  holds all 65536 states of each to `codebookValue`).
- The rotated row is main's `tf_exl3_rotate_in`: fp16((x * suh) through the seven butterfly stages * fp32(1/sqrt(128))).
- The dot, per column, in one order: k = 0 .. K-1 ascending; product = fp32(x'_k) * fp32(W_q[k][c]), exact in fp32
  (11-bit by 11-bit significands); TwoSum: next = fl(high + product), part = fl(next - high),
  low = fl(low + fl(fl(high - fl(next - part)) + fl(product - part))), high = next; the output is fl(high + low).
  Each `next` rounds, and its error, exact by TwoSum, goes into `low`; the column's one rounding to its value is the
  final fl(high + low). This is `tf_exl3_matmul_impl`'s order for a row, so the bits equal that kernel's.
- `tf_exl3_rotate_out` (unchanged) then rotates by 128, scales by svh and adds the bias.

## Gates and results

- W_q: one-hot rotated rows (x a Hadamard row, suh 1) make sums[c] = x'_j * W_q[j][c] exactly; the kernel's are
  bit-equal to `unpack` for every codebook and width (27 cases) and to the oracle's real mcg 8.00 bpw block.
- Dot: the kernel's sums are bit-equal to the serial reference at `wq_a`, `wkv` (every column), `wq_b`, a `wo_a`
  group as a column view of an 8192-column parent, `wo_b`, the shared w1/w3 and w2 and `ix_wq_b` (first, middle and last
  128-column blocks), and its sums and outputs are bit-equal to `tf_exl3_matmul_hoisted`'s at every column.
- float64, reported only: the real block against `dequantize` gives max |gpu - f64| 6.5e-5 at max |y| 0.48 on M4 Pro;
  the rotated input's fp16 rounding is the format's.
- Planted faults: dropping the TwoSum error term fails six GPU tests; a wrong placement fails ten.
- Kernel contract on M4 Pro, `tf-kernel-contract --only exl3`: `SUMMARY 5 kernels: 5 pass gates 1-4, 0 fail, 0 known
  findings; 1 controls: 1 red as planted, 0 missed; 0 limit problems`; offline, M1 and M2 build it for 32 threads.
- Speed on M4 Pro (`tf-exl3-bench --mode one`, 6 halves mul1, GPU seconds, mean of 30): `tf_exl3_matmul_hoisted`
  against `tf_exl3_matmul_row` at K x N: 5120 x 2304 372/303 us, 2304 x 5120 235/171, 1280 x 32768 746/460,
  4096 x 1024 289/225, 8192 x 5120 801/569, 5120 x 1280 357/300, 5120 x 512 359/280; each run's bits equal.
