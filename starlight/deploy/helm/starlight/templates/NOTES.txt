The first-owner setup link is in the init job's log. It works once and expires after 24 hours:

  kubectl --namespace {{ .Release.Namespace }} logs job/{{ include "starlight.fullname" . }}-init
{{- end }}

Nodes enrol against the node listener, which must reach Starlight as plain TCP so the node's certificate is seen:

  kubectl --namespace {{ .Release.Namespace }} get service {{ include "starlight.fullname" . }}-nodes

Create an enrolment command:

  kubectl --namespace {{ .Release.Namespace }} exec deploy/{{ include "starlight.fullname" . }} -- starlight nodes token --pool default

Check the installation:

  kubectl --namespace {{ .Release.Namespace }} exec deploy/{{ include "starlight.fullname" . }} -- starlight doctor
