# TensorFold app 1.0.0-beta.8

This macOS app beta bundles the verified TensorFold 1.1.0 engine for Apple silicon on macOS 13.3 or later.

## In this beta

- Search the full text of your conversations, jump to matching messages, and navigate long chats with the outline and pinned messages.
- Keep source references with document collections and citations, export readable conversations, and review local workspace backups before restoring them.
- Choose an interface language from the existing language selector, with new authored translations throughout the app. Conversation source text, filenames and original diagnostics remain identifiable; translation quality can vary.
- Run repeatable model benchmarks from Models, review measurements and retain per-model profiles and previous results. A benchmark measures the selected workload and hardware, not model quality.
- Set up optional Gmail, Calendar, Slack, Discord and Telegram connections, including owner-controlled Telegram remote chat and room access. Each connection needs its own account setup; live service behaviour depends on its permissions and provider.
- Review trusted compute hosts, SSH prerequisites, headless setup, pinned model plans and durable operation receipts in Compute and clusters. Native single-host endpoints and their credentials remain separate from management access.
- Use the bundled engine's prompt-cache planner rather than reserving a fixed eight GiB. Model-cache scans handle supported larger metadata and skip filesystem sidecar files.

## Limits and qualification

Cortheon web research remains disabled, and Living Weights remains experimental. The new cluster controls do not enable generic distributed inference or mixed Mac/CUDA weight distribution: their native adapters, peer rendezvous and hardware qualification remain open. Discovering an adapter does not prove an RDMA transfer, and a successful single-host canary does not qualify a cluster.

Google and messaging connections require user-owned accounts and permissions; synthetic local checks do not establish every live-account workflow. No new iPhone, Android or Apple Watch installer is included. Media creation work on the separate contribution branch is not part of this beta.

Download the signed Mac installer from https://tensorfold.dev/download/mac, or use the in-app update prompt after the signed feed detects this version. Historical installers remain separate from the current version.
