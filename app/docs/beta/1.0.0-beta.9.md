# TensorFold app 1.0.0-beta.9

This macOS app beta bundles the verified TensorFold 1.1.0 native engine for Apple silicon on macOS 13.3 or later.

## In this beta

- Google Workspace setup explains when no accounts are connected and provides the existing Google sign-in flow to add an account or use another address.
- Account-list failures show a retry action, and Gmail or Calendar authentication failures refresh connection status so an expired session can be reauthorized.
- Unsaved mail drafts remain available during reconnection, and reviewed sends can be prepared again after authentication changes.
- Hosted model context limits follow the selected account and endpoint while preserving an explicitly configured cap.
- Document folders are traversed in name order consistently across filesystems.

## Limits and qualification

Google accounts are connected through Google consent using a user-owned Desktop OAuth client; TensorFold does not discover accounts from the operating system or browser, and entering an address alone does not authenticate an account.
The original beta account-detection report did not include an exact screen, operating system, build or updated reproduction result; this release fixes the verified empty-state and authentication-recovery problems found in the current app.
Regression checks use synthetic accounts and mocked service responses, so they do not establish every live Google account workflow.

The beta.8 limitations still apply, including disabled Cortheon web research, experimental Living Weights and incomplete distributed-inference qualification.
No new mobile or watch installer is included.

Download the signed Mac installer from https://tensorfold.dev/download/mac, or use the in-app update prompt after the signed feed detects this version.
