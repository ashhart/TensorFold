# TensorFold 1.0.0-beta.6

Release candidate; publication requires the signed artifact audit and native Mac qualification.

This beta adds a simpler Bots workspace, isolated local bot work and clearer feedback when a model needs help or a run fails.

- Create a bot with a name, responsibility, model and permission scope. Open its compatible chat, or start a new one. Pause and archive retain its conversation history.
- On Apple silicon with macOS 26 or later, a VM bot can set up a verified private Apple container runtime and work inside its own persistent Linux workspace. Its model stays local, the guest has no network or host-folder mounts, and each command has time, output, memory and disk limits. VM files remain until you explicitly erase them. Guest desktop, browser takeover and persistent background services are not supported in this beta.
- A local chat model can ask one short question with optional choices or free text. Answer or Skip continues the same run; Stop interrupts it. Answers do not grant tool permissions, and questions interrupted by restart cannot resume an old run.
- Model setup can test an actual short generated response through the selected endpoint, with timing and clear failure feedback. This test may use a billable request on a cloud endpoint.
- Endpoint testing keeps saved credentials bound to their saved destination and launch profile; an empty draft key remains empty.
- Completed approvals no longer leave a successful run marked blocked. Recorded failed, blocked, cancelled and unverified outcomes stay visible below the answer, with access to the activity that explains them.
- Connection, sign-in, memory, context and timeout errors have specific recovery guidance. Recovering does not automatically replay a task.
- Composer fixes protect drafts when a run cannot start, prevent duplicate sends and composition-key submission, and clear queued follow-ups when you press Stop.
- Daily routines accept an explicit time zone and show their next run, including daylight-saving transitions.
- Muted text uses the active palette to improve readability across light and dark surfaces.
- Incognito excludes automatic conversation journals, checkpoints, job records, archive backups and memory proposals, and hides private conversations from other chats and remote mirrors; prior betas did not cover all these paths. CLI agents and helpers that retain app content are unavailable in Incognito. Your selected providers, approved workspace outputs and explicit exports can retain their own records; existing historical data is not automatically removed.
- Packaging omits unused browser voice payloads and upstream demo/development files, while retaining the Node speech runtime and its attribution.

The built-in engine, Minimal and Full onboarding, local model discovery, Cortheon, Kokoro voice and phone-control work remain part of this release candidate; their native qualification is tracked separately.

Living Weights remains experimental: training can change a private model, but dependable factual recall and complete rollback graph metadata are not qualified. Mobile clients and physical-phone control remain previews. Model responses can still be inaccurate, including claims about failed actions; consult the recorded run activity.
