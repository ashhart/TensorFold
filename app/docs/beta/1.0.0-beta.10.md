# TensorFold app 1.0.0-beta.10

This macOS app beta bundles the released TensorFold 1.1.4 native engine for Apple silicon on macOS 13.3 or later.
The engine archive is pinned to its published SHA-256 and its internal file checksums are verified before packaging.

## In this beta

- Update the bundled native engine from 1.1.0 to 1.1.4. See the [engine release notes](https://github.com/ashhart/TensorFold/releases/tag/v1.1.4) for its platform-specific changes and measurements.
- Benchmarks use the engine's community-v2 protocol, recording request routes, cache format and natural sampled stops. Saved community-v1 results remain readable with their original protocol label.
- Google sign-in accepts Google's issuer callback parameter and shows a useful explanation when sign-in fails.
- Update checks and downloads work through fake-IP proxies while retaining the destination checks used for Hub downloads.
- The model library uses the engine's geometry admission checks before offering a checkpoint for loading.
- Update the shipped HTTP, email and schema-validation dependencies to patched versions.

## Limits and qualification

The beta.9 limitations still apply, including disabled Cortheon web research, experimental Living Weights and incomplete distributed-inference qualification.
Google and messaging connections require user-owned accounts and permissions; synthetic service checks do not establish every live-account workflow.
Window-close flashing reported in Full mode remains under investigation.
No new mobile or watch installer is included.

Download the signed Mac installer from https://tensorfold.dev/download/mac, or use the in-app update prompt after the signed feed detects this version.
