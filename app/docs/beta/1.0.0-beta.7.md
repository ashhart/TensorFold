# TensorFold app 1.0.0-beta.7

This macOS app beta bundles TensorFold engine 1.0.12.

- A cleaner Models workspace separates My models from Discover, with model details, editable per-model context and sampling profiles, favourites and local model comparisons.
- Task starters help you summarise files, work with code or plan a task without sending before you are ready.
- The message composer supports native editing shortcuts and menus, sent-message editing with preserved revisions, and drafts kept with their own conversation across navigation and restart.
- File attachments show individual filenames and processing status, with editable extracted text and explicit handwriting/OCR uncertainty.
- Project memory supports recoverable Trash and restore, and long tool output is compressed for the model while keeping the full output available for review.
- Model downloads, switching and recovery, connection setup and personal routine safeguards have been improved.
- Engine compatibility fixes enable supported single-Mac sampling settings, handle learning deletion states and private learning backups, and make an explicit no-reasoning request disable native thinking.
- The sidebar can notify you about a new app version and guide its signed download and restart.

Cortheon remains disabled in this beta. Living Weights remains experimental, and phone/watch availability depends on the platform, pairing and permissions; this desktop release does not include a new mobile installer. New opt-in engine capabilities such as Recall, rollback controls and vision configuration are not all exposed as GUI settings yet.

Apple silicon macOS 13.3 or later. This is a beta release, with broader hardware and live-account qualification continuing.
