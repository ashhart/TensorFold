# TensorFold for Mac 1.0.0

The first stable desktop release is for Apple silicon Macs running macOS 13.3 or later.
It bundles TensorFold engine 1.2.0. Windows and Linux builds remain previews.

- Ask TensorFold opens as a compact input bar. You can explicitly select a window,
  inspect the captured image and available text, then choose what to send.
- The main Mac window closes into the background, with the TensorFold mesh logo in the menu bar.
- Engine updates can be checked, downloaded and selected independently of app updates.
  Selection waits for local work to finish, and the bundled engine remains available for rollback.
- Connection health and the unified inbox expose account state and provider errors.
  Google Workspace and Microsoft accounts require their configured credentials and consent.
- Portuguese joins the bundled interface languages.
- Pairing, model geometry admission and app updates retain the fixes on the engine's main branch.

Conversations and model files stay in their existing locations. Review provider and capture permissions
before sharing content with a hosted model. Cortheon remains disabled in this release.

Windows native execution and installation are still awaiting qualification. Linux preview receipts
cover the tested VM configurations, not every desktop or GPU. Platform-specific automation and
messaging depend on the operating system and configured services.
