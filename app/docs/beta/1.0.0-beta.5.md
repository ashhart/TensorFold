# TensorFold 1.0.0-beta.5

This beta gives the app a look of its own, built entirely from the TensorFold brand, and adds computer use and Cortheon.

- Computer use: type `/computer-use` and a task (or mention `@computer`) and the agent can operate Mac apps for you. It opens the app, reads the window's buttons, fields and menus, and clicks, types, presses keys or scrolls. Each app needs your approval once per task. A bar at the top of the screen shows which app it is operating, with a Stop button; `/computer-use stop` also ends it. It never operates TensorFold itself and never types into password fields. It needs Accessibility permission, which macOS asks for the first time.
- Cortheon: a switch on the Models page has the built-in engine research the web and follow a reasoning plan before answering. A chat running with it shows a Cortheon badge, its progress while it works, and the searches, pages and sources under each answer. It sends search queries built from your chats to a web search service, so leave it off for confidential work.
- The built-in engine moves to TensorFold 1.0.10.
- Qwen3.8 Flash Next joins the model list. It is the 6-bit checkpoint, about 147 GiB, so the app offers it only on Macs with enough memory and disk, such as a 256 GB Mac Studio. It is the top pick on M5 Ultra.
- Qwen3.8-27B stays in the list with its DFlash2 drafter and remains the top pick on M5 Max and M3 Ultra.
- The theme picker now offers TensorFold, Navy and Glass. Themes styled after other apps are gone. If you used one of them, the app switches you to the TensorFold theme. Custom palettes are kept as they are.
- New base surfaces, borders, status colours, corner radii and "thinking" animation, all drawn from the TensorFold brand colours.
- Text that used to say "Studio" now says TensorFold.
- Shell commands that automate other apps (osascript, shortcuts, cliclick, automator) now always ask before running, even with full access.

Mobile clients remain preview software, with physical-device qualification and build-tool supplier advisories still pending.
