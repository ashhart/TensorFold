# Document workflows

Chats can select up to 64 local document collections. An explicit empty selection permits no document or table retrieval. Older chats retain the previous enabled-collection behavior until an explicit selection is saved. Selection changes do not rewrite prior messages or remove already sent context; start a new conversation to exclude previously supplied evidence.

The host filters document settings before legacy document/table/general retrieval and scopes indexed search and evidence reads before any original verification. The existing local-provider, bot, destination and connector restrictions remain in force. Changing the owning chat selection, removing its owner, or changing an allowed source configuration invalidates already prepared context before the next model request.

The processing queue persists filenames, source configuration and per-file checkpoints in protected profile storage. It processes one physical parser at a time. Each finished file is committed atomically to the protected index; failures remain independent. Pause/cancel discard an extraction that has not reached its commit checkpoint. Parsing cannot pause within a file, so resuming reparses that file. After interruption, pending files remain paused until explicit resume; completed files are not rescanned. A new scan inventories enabled collections again within the existing file, traversal, byte, character and passage limits.

The source viewer verifies the requested citation revision again and displays escaped original text beside newly extracted text, parser identity, cited passage and truncation notices. Each pane is bounded to 120,000 characters. HTML is plain text; no embedded scripts, remote assets or document actions run. Binary originals are not rendered inline. PDF extraction has no verified page map, OCR or executable native preview; the viewer states this rather than inventing page anchors. Original files remain unchanged.

No new runtime dependencies or model calls are required. Focused tests cover mixed outcomes, independent retry, pause/cancel races, restart checkpoints, physical concurrency, collection revocation, stolen evidence handles, original/extracted distinctions, escaped hostile markup, preview bounds, changed sources, duplicate saves and stale chat callbacks. Browser/native qualification is separate from these synthetic tests.
