# Hardware makers' logos

Shown on Home beside the machine that runs the AI, one per maker (a cluster of mixed machines shows several), only
to say whose hardware it is. Every logo belongs to its owner. `src/brand.ts` (`hardwareOf`) says which chip maps to
which logo.

| File | Source |
|---|---|
| apple.svg, nvidia.svg, amd.svg, intel.svg, qualcomm.svg | [Simple Icons](https://simpleicons.org) 16.35.0 (CC0), in the brand colour it gives |

Taken on 13 October 2026. A maker known to `hardwareOf` without a file here shows its initial.
